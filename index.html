Settings

Each clan keeps its own separate players and fight history. Pick a clan above to switch to its data, or add a new one to start a fresh, empty tracker.

"Delete All Data" only wipes the currently selected clan's players/fights — use "Delete Selected Clan" above to remove a whole clan (e.g. a mistyped name) from the list.

Each provider keeps its own key. Keys are saved only in this browser and never sent to the database.

Known Players

This is the canonical spelling for each player — it's what the AI is told to match screenshot names against, and it controls which rows appear in the Table tab. Rename a player here to fix a name everywhere at once; two names typed the same way (ignoring case) get merged automatically.

Tick Left clan for people who are no longer in the clan: their old results stay, but they no longer get an empty row in months where they didn't play. Members who are still in the clan but don't play: just leave them unticked and they keep their row.

Data Management

Clans, players and fights are stored in the Supabase database (everyone can view, only the logged-in admin can edit) and cached in this browser. API keys are saved only in this browser and is never sent to the database. Export JSON on the "Table" tab makes a backup file (without the API key).

One-time migration: uploads data that only exists in this browser (from the old localStorage-only version) to the database.
